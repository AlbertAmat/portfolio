About

I'm a senior software developer based in Barcelona. By day I build web applications. Outside work I study cybersecurity, with a focus on malware reverse engineering and on working out how a computer got infected in the first place.

I like small, open-source tools that do one thing well, and I publish most of what I build.

My main tools are Vue, Node.js, Java and Go. I'm also learning reverse engineering and digital forensics.

I'm open to contributing to open-source and cybersecurity projects. If you have one that needs a hand, get in touch.

Projects

Vaultisse (open source)

A free, open-source web app for cataloging your book collection: where each book is, who has it on loan, and automatic lookup by ISBN. It has about 80 stars on GitHub, takes contributions from other developers, and ships as a Docker image with the interface in English, Spanish, Catalan and Italian.

Vue, TypeScript, Node.js, PostgreSQL, Docker.

Website | Live demo | Documentation | Source code

Azarov Untraceable Chat (in progress)

An anonymous web chat with end-to-end OpenPGP encryption. The Go relay server keeps no logs and no database: messages live in memory only and are deleted after a set time.

Go, OpenPGP.
