Posted 5 November 2026

This is the first post on the new site. It is plain HTML and one small stylesheet, because I think that if the writing is good, the page does not need to be pretty.

I plan to write here about the things I work on: web development, the open-source projects I maintain, and what I learn while studying malware analysis and digital forensics.

Writing a new post

To add a post, copy this file in the posts folder, give it a new name, change the title and the text, and add a line for it in blog.html and on the home page.

<h2>Title</h2>
<p class="date">Posted 1 January 2027</p>
<p>Your text here.</p>
